# ELF64 statisches x86-64-Programm – Hex-Dump

## Programmlogik
1. `read(0, buf, 200)` – Zeile von stdin
2. Eventuelles finales `\n` entfernen
3. Buchstaben-Reverse (Two-Pointer)
4. `write(1, reversed, n)` + `write(1, "\n", 1)`
5. `sys_exit(0)`

Keine libc, keine Sektionsüberschriften, nur `read`, `write`, `sys_exit`.

## So anwenden (eine Zeile)
```bash
echo -e '\x7f\x45\x4c\x46... (alle Bytes)' > /dev/null   # nein – so:
xxd -r -p > revline && chmod +x revline
echo "Hallo\n" | ./revline   # → "ollaH\n"
```

Oder in einem Terminal:
```bash
printf '%s\n' "Hallo" | ./revline   # gibt "ollaH"
```
