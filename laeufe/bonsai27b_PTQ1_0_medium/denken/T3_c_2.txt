The user wants a complete C program for Linux that implements the FizzBuzz problem for numbers 1 to 30. Requirements:
- "FizzBuzz" if divisible by 15
- "Fizz" if divisible by 3
- "Buzz" if divisible by 5
- Otherwise print the number
- Each line ends with a newline
- Exit code 0
- Compile with gcc -O2
- Can use standard C library

The output format needs to be:
BEGIN_C
<code>
END_C

Let me write a simple C program:

```c
#include <stdio.h>

int main(void) {
    for (int i = 1; i <= 30; i++) {
        if (i % 15 == 0) {
            printf("FizzBuzz\n");
        } else if (i % 3 == 0) {
            printf("Fizz\n");
        } else if (i % 5 == 0) {
            printf("Buzz\n");
        } else {
            printf("%d\n", i);
        }
    }
    return 0;
}
```

This is straightforward and correct. Let me verify:
- 1-2, 4-5: print numbers
- 3: Fizz
- 5: Buzz
- 6: Fizz
- 7-8: numbers
- 9: Fizz
- 10: Buzz
- 11-14: numbers
- 15: FizzBuzz
- etc.

Exit code is 0 from `return 0`. Each line ends with \n. Uses only stdio.h. Compiles fine with gcc -O2.
