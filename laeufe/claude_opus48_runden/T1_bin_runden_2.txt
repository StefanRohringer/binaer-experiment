## Lösung

Ich konstruiere eine minimale statische ELF64-Datei für Linux x86-64:

**Layout:**
- ELF-Header (64 Bytes), Lade-Basis `0x400000`
- Ein Program-Header `PT_LOAD` (56 Bytes), R+X
- Code ab Offset `0x78` (vaddr `0x400078` = Entry Point)
- Nachricht `"Hallo Welt\n"` ab Offset `0x97` (vaddr `0x400097`)

**Code (Maschinenbefehle):**
```
mov eax,1          ; sys_write
mov edi,1          ; fd = stdout
mov esi,0x400097   ; Adresse der Nachricht
mov edx,11         ; Länge
syscall
mov eax,60         ; sys_exit
xor edi,edi        ; Exit-Code 0
syscall
```

Nachricht: `48 61 6c 6c 6f 20 57 65 6c 74 0a` = `Hallo Welt\n` (11 Bytes).

Dateigröße: 162 Bytes (`0xA2`).
