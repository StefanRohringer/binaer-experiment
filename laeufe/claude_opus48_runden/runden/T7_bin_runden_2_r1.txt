# Analyse und Lösung

Ich habe einen rekursiven Abstiegs-Parser direkt in x86-64-Maschinencode umgesetzt:

- **`_start`**: `read(0, buf, 256)`, `r15` = Zeiger auf aktuelles Zeichen, ruft `parse_expr`, gibt Ergebnis dezimal aus, `exit(0)`.
- **`skip`**: überspringt Leerzeichen (0x20).
- **`parse_factor`**: Zahl oder `( expr )`.
- **`parse_term`**: `* /` (idiv trunkiert Richtung 0).
- **`parse_expr`**: `+ -`.
- Grammatik links-assoziativ, Punkt-vor-Strich, Klammern.

Speicherlayout: Ein `RWX`-`PT_LOAD`-Segment ab `0x400000`; Eingabepuffer bei `0x402000`, Ausgabepuffer bei `0x402200` (bss, kernel-nullt). `r15` ist die globale Leseposition, Zwischenwerte liegen auf dem Stack (balancierte push/pop).

Division `-7/2` = `-3` ✓ (x86 `idiv` schneidet Richtung null ab).

Datei: 120 Byte Header + 325 Byte Code = 445 Byte (0x1BD).
