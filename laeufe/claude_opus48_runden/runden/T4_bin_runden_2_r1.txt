## Analyse

Ich erstelle eine minimale statische ELF64-Datei mit einem einzigen RWX-Segment. Puffer liegen im per `memsz` erweiterten (nullgefüllten) Bereich ab `0x401000`.

**Ablauf des Codes:**
1. `read(0, 0x401000, 201)` → Länge in `rax`
2. Falls `≤0` → exit(0)
3. Letztes Byte `== '\n'`? → Länge dekrementieren
4. Bytes rückwärts nach `0x401100` kopieren
5. `'\n'` anhängen, `write(1, 0x401100, len+1)`
6. `exit(0)`

**Layout:** ELF-Header (64) + Program-Header (56) + Code (106) = 226 Byte (`filesz=0xE2`), `memsz=0x2000`, Einsprung `0x400078`.

Der Code wurde von Hand assembliert; Sprungweiten (`jle +76`, `jne +3`, `jz +15`, `jmp -20`) sind geprüft.
