Hier ist mein C-Programm:

```c
#include <stdio.h>
#include <string.h>

int main(void) {
    char buf[202];
    if (fgets(buf, sizeof(buf), stdin) != NULL) {
        size_t len = strlen(buf);
        if (len > 0 && buf[len - 1] == '\n') {
            len--;
        }
        for (size_t i = len; i > 0; i--) {
            putchar(buf[i - 1]);
        }
    }
    putchar('\n');
    return 0;
}
```

Erläuterung:
- `fgets` liest eine Zeile (bis zu 201 Zeichen + Nullterminator, ausreichend für 200 Byte + Zeilenumbruch).
- Der abschließende Zeilenumbruch wird entfernt, falls vorhanden.
- Die Zeichen werden in umgekehrter Reihenfolge ausgegeben.
- Am Ende folgt ein Zeilenumbruch, und der Exit-Code ist 0.
