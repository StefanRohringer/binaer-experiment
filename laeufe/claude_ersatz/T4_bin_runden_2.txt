# Analyse der Aufgabe

Ich baue eine minimale statische ELF64-Datei mit einem einzigen RWX-LOAD-Segment:

**Programmlogik (x86-64 Syscalls):**
1. `read(0, buf, 200)` → Länge in `rax`
2. Bei `rax<=0` → direkt exit 0
3. Falls letztes Byte `\n` → Länge um 1 verringern
4. Puffer in-place umdrehen (zwei Zeiger)
5. `\n` anhängen, `write(1, buf, len)`
6. `exit(0)`

Puffer liegt als BSS (`memsz > filesz`) bei vaddr `0x4000DC`. Entry bei `0x400078` (direkt nach den 120 Byte Headern).

Die Sprünge, SIB-Adressierungen (`[rsi+rax-1]`, `[rsi+r8]` usw.) und REX-Präfixe wurden byteweise berechnet. Randfälle: leere Zeile (nur `\n`) → gibt nur `\n` aus; EOF ohne Daten → keine Ausgabe, exit 0.

**Layout:** ELF-Header (64) + Program-Header (56) + Code (100) = 220 = `0xDC` Byte.
